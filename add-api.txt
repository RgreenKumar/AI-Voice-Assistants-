Here are the steps to get each API key and the exact format to copy and paste into your .env file.

1. Get GROQ_API_KEY
Open: Groq Console
Sign in or create an account.
In the left menu, open API Keys.
Click Create API Key.
Enter a name such as my-project.
Click Create.
Copy the generated key.

Paste it like this:

GROQ_API_KEY=gsk_your_actual_groq_key_here
2. Get NEWS_API_KEY
Open: NewsAPI
Click Get API Key or Register.
Create a free account and verify your email.
Log in to the dashboard.
Your API key will be displayed on the account page.
Copy the key.

Paste it like this:

NEWS_API_KEY=your_newsapi_key_here
3. Get SERPER_API_KEY
Open: Serper Developer Dashboard
Sign in using Google.
Open the dashboard.
Click Create API Key if one is not already generated.
Copy the API key shown in the dashboard.

Paste it like this:

SERPER_API_KEY=your_serper_api_key_here
Final .env file format

After getting all three keys, your .env file should look like:

GROQ_API_KEY=gsk_xxxxxxxxxxxxxxxxxxxxxxxxx
NEWS_API_KEY=xxxxxxxxxxxxxxxxxxxxxxxxxxxx
SERPER_API_KEY=xxxxxxxxxxxxxxxxxxxxxxxxxx
